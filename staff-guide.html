Student Management Staff Guide

For our front desk and staff: sign in, view classes, set a class age range, and add students.

Open Student Management

App address: https://gsaachievers.github.io/student-management/

1. Sign in and choose your center

  1. Open Student Management using the button above.
  2. Enter the email and password your manager has given you. Select Sign in.
  3. Choose Lucknow or Noida from the Center dropdown. Check this before making any changes.

Ask your manager privately for login details. Passwords are not included on this guide page.

2. View classes and students

  1. Find the day and time in the weekly timetable. It runs Monday–Sunday, 10 AM–8 PM, in one-hour slots.
  2. Each tile shows its age range when set, student count, and a preview of the names.
  3. Click a tile to see all students and their ages. Names on the tile wrap to two lines, then end with … when the list is longer.

On a phone, scroll the timetable sideways to see other days. This is a recurring weekly class schedule.

3. Set or change the class age range

The class name on each tile is its age-range label.

  1. Choose the correct center and click the class day/time tile.
  2. Under Batch age range, select Age 3–6, Age 6–9, or Age 9–12.
  3. Select Save age range. Wait for Age range saved.

The new age-range label now appears on that class tile. You can return and change it later.

4. Add a student to that class

  1. While the class tile is open, select + Add to batch.
  2. For a new child, leave Register a new student selected. Enter their Student name and Age.
  3. Check the Day and Batch time.
  4. Select Save student. Check that the child now appears in the class list.

Child already registered? Select them from the Student dropdown instead of registering them again. This adds the class to their existing student record.

One class is the usual default. Use + Additional batch (optional) only if another class is needed. Changing an age-range label does not automatically move students.

5. Correct a class assignment and finish

To remove a student from a class, open that tile, select Remove from batch beside their name, and confirm. Their student record remains available for future classes.

To move a child, first add the existing student to the new class, check it saved, and then remove their old class assignment.

Refresh the page to see updates made on another device. If a save or sign-in fails, note the message and contact your manager. Select Sign out when finished on a shared computer.
